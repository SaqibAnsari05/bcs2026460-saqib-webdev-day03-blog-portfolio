# Day 03 — Personal Blog & Portfolio

A responsive three-page student portfolio made with semantic HTML and CSS.

## Pages
- `index.html` — home page
- `about.html` — about, learning path, interests, contact
- `blog.html` — featured note and blog cards
- `styles.css` — shared responsive dark theme with light-green accents
- `images/` — local SVG illustrations

## Run locally
Open this folder in VS Code and use Live Server to open `index.html`.

## Before submitting
- Check all three pages and the navigation links.
- Check that the images load on every page.
- Test desktop and mobile widths.
- Replace the sample email address in `about.html` with your own email if you want to use the contact link.
- Make sure the GitHub repository contains all files and the `images` folder.
