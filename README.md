
# Saqib's Blog & Portfolio

Welcome to my personal blog and portfolio website! This project showcases my introduction, interests, and blog-style content using HTML and CSS.

## About the Project

This is a simple, responsive multi-page website created as part of my Day 3 Web Development practice.

The website uses a dark theme with light green accents for a clean, modern look.

## Pages

- **Home (`index.html`)** — Introduction and portfolio homepage.
- **About (`about.html`)** — Personal introduction and background.
- **Blog (`blog.html`)** — Blog-style content and notes.

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git and GitHub

## Features

- Multi-page personal website
- Dark background with light green accents
- Responsive layout for different screen sizes
- Custom SVG illustrations
- Navigation between pages
- Simple and readable design

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Navigate through the Home, About, and Blog pages.
